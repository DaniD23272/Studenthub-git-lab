# StudentHub Git Lab

## Descripción

Laboratorio práctico de Git y GitHub para aprender y aplicar un flujo de trabajo colaborativo utilizando un repositorio compartido.

## Objetivos

* Crear y administrar un repositorio Git local.
* Realizar commits y consultar el historial.
* Trabajar con ramas.
* Realizar merge y resolver conflictos.
* Utilizar rebase.
* Conectar el repositorio local con GitHub.
* Realizar push y pull.
* Trabajar de manera colaborativa mediante GitHub.
* Crear y revisar Pull Requests.

## Equipo

| Rol          | Integrante   |
| ------------ | ------------ |
| Estudiante A | Daniela      |
| Estudiante B | Sara         |

## Herramientas

* Git
* GitHub
* Git Bash
* Editor de código

## Flujo de trabajo

1. Crear y configurar el repositorio local.
2. Realizar commits.
3. Conectar el repositorio con GitHub.
4. Clonar y sincronizar el repositorio.
5. Crear y trabajar con ramas.
6. Realizar merge y resolver conflictos.
7. Practicar rebase.
8. Crear y revisar Pull Requests.
9. Verificar el historial final del proyecto.

## Comandos principales

```bash
git init
git status
git add
git commit
git diff
git log
git branch
git checkout
git checkout -b
git merge
git rebase
git remote
git push
git pull
git clone
```

## Verificación

Para consultar el historial y las ramas del proyecto:

```bash
git log --oneline --graph --decorate --all
git branch -a
git remote -v
```
